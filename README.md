# 水脉苗韵 · 水书与苗族古歌数字化成果

陕西师范大学「文绎苗梦」团队的成果展示网页。水书与苗族古歌两条线索同为国家级非物质文化遗产，本页把三地田野采集、平台传播、文本出版与数字化课程、水书材料与互动小程序整理成一份可浏览的档案。

## 页面结构

| 章节 | 内容 |
|---|---|
| 00 成果总览 | 四类成果导览 |
| 01 田野现场 | 19 张田野影像、4 段现场视频、3 段唱腔录音 |
| 02 传播矩阵 | 微信公众号「水书新生」「文绎苗梦」、视频号、小红书账号与索引方式 |
| 03 苗族古歌成果 | 七项文本成果、六位传承人名录、54 帧苗族九支系服饰图版、《蝶魂回响》故事集、校本教材与 AI 数字化课程 |
| 04 水书成果 | 水书抄本与字例、《古敢水族乡水族文化读本》对照表、志愿服务计划书、互动小程序「水语寻声」实机截图与演示 |

## 本地预览

双击 `index.html`（建议 Chrome / Edge）。全部资源为相对路径，无需服务器、无需联网。

## 部署到 GitHub Pages

1. 新建 Public 仓库
2. `Add file → Upload files`，把本目录内容分批拖入（GitHub 单次上限 100 个文件，本包 141 个，建议分两批）
3. `Settings → Pages`：Source 选 `Deploy from a branch`，Branch 选 `main`，目录 `/ (root)`，Save
4. 约 1–2 分钟后访问 `https://用户名.github.io/仓库名/`

`.nojekyll` 用于关闭 Jekyll 处理，避免静态资源被忽略。

## 说明

- 视频与音频需点击播放键；图片可点开大图，Esc 关闭；右上角月亮切换深浅色。
- 收录三本参考书（`pdf/` 内）。《王安江版苗族古歌》上下册共约 900MB，超出仓库建议体积，未包含。
- 所有影像来自团队田野采集与自有设计，其中含受访者肖像，仅用于本项目成果展示与教学研究，不作商业用途。
